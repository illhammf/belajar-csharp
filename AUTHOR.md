### About This Repository

`belajar-csharp` contains learning materials, notes, examples, exercises, and simple case studies covering C# fundamentals through Object-Oriented Programming (OOP), Exception Handling, Collections, and LINQ.

The repository is organized into 16 learning sessions to make the learning process easier to follow step by step.

### Purpose

This repository is intended for:

- Personal learning documentation
- Beginner-friendly C# practice
- Programming exercises
- Reference for basic C# concepts
- Documentation of the learning journey
