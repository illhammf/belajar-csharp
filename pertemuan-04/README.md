# 📚 Apa Itu Conditional Statement?

Conditional Statement adalah struktur program yang digunakan untuk menentukan tindakan berdasarkan suatu kondisi.

Sederhananya:

```text
Jika kondisi benar
    jalankan program A

Jika kondisi salah
    jalankan program B
