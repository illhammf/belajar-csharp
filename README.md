# Belajar C#

Repository ini berisi catatan dan contoh kode pembelajaran bahasa pemrograman **C#** dari dasar hingga konsep Object-Oriented Programming (OOP), Collections, dan LINQ.

Repository ini dibuat sebagai dokumentasi proses belajar C# secara bertahap melalui beberapa pertemuan dengan contoh program sederhana yang dapat langsung dicoba.

## Tujuan

Repository ini dibuat untuk:

- Mempelajari dasar-dasar bahasa C#.
- Memahami syntax dasar C#.
- Memahami konsep Object-Oriented Programming (OOP).
- Berlatih membuat program sederhana.
- Memahami cara mengolah data menggunakan Collections dan LINQ.
- Menjadi dokumentasi perjalanan belajar C#.
- Menjadi referensi ketika membutuhkan contoh kode dasar C#.

# Menjalankan Program

Repository ini menggunakan file C# secara individual.

Untuk menjalankan salah satu file, gunakan:

    .\run.ps1 pertemuan-01/01_nama_file.cs

Contoh:

    .\run.ps1 pertemuan-16/15_studi_kasus_linq.cs

Nama file dapat disesuaikan dengan file yang ingin dijalankan.
